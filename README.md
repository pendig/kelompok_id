# Kelompok.id Landing Page

Landing page sederhana untuk [Kelompok.id](https://www.instagram.com/kelompok_id), dibangun dengan Astro.

Kelompok adalah platform open-source untuk membantu organisasi membangun profil publik, membagikan kegiatan, membuka donasi secara transparan, dan melaporkan dampak.

## Menjalankan lokal

```sh
npm install
npm run dev
```

Build produksi:

```sh
npm run build
```

## Brand

Logo, warna, dan arah produk mengacu pada aset resmi proyek [pendig/kelompok](https://github.com/pendig/kelompok).
